# موقع الكورس

منصة تعلم عربية للويب: 44 درسا في سبع مراحل، ومكتبات للمنصات والبرومبتات والقوالب،
وقاموس مصطلحات، وبحث عربي محلي — كلها صفحات ثابتة تُنشر على GitHub Pages.

## التشغيل
```bash
npm ci
npm run dev      # تطوير
npm run build    # بناء الإنتاج
npm run preview  # تقديم dist تحت المسار الفرعي الحقيقي
npm run qa       # كل الفحوص والاختبارات
```

## إضافة درس
1. أنشئ `src/content/course/NN-slug.mdx` بالحقول الموصوفة في `CONTENT_MODEL.md`
2. اكتب المتن مستخدما `## ` للأقسام — قائمة المحتويات وفهرس البحث يُبنيان منها تلقائيا
3. `npm run qa`

## تعديل درس
عدّل ملف الدرس نفسه ثم `npm run qa`. المحتوى منفصل عن المكونات، فلا حاجة لتعديل الكود.

## إعادة النشر
ادفع إلى `main` أو شغّل سير العمل يدويا من تبويب Actions. النشر لا يتم إلا بعد نجاح
كل الفحوص: الأنواع، واللغة، والتباين، والبناء، والروابط، والأصول، والملفات الممنوعة،
واختبارات الواجهة والوصول.

## المسار الأساسي
يُشتق في سير النشر من اسم المستودع، ومحليا قيمته `/pprommept/`.
لتغييره محليا: `SITE_BASE=/name/ npm run build`.

## الوثائق
`CLAUDE.md` القواعد الدائمة · `PRODUCT_WEB.md` المواصفة · `INFORMATION_ARCHITECTURE.md` خريطة الموقع ·
`CONTENT_MODEL.md` نموذج المحتوى · `DESIGN_SYSTEM_WEB.md` نظام التصميم ·
`DESIGN_DECISIONS.md` قرار اتجاه التصميم · `DECISIONS.md` القرارات التقنية ·
`STATE.md` الحالة · `QA_REPORT.md` تقرير الجودة
